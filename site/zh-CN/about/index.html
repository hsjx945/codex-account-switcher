Codex Account Switcher 是什么？

Codex Account Switcher 是一款面向普通 Mac 用户的免费独立菜单栏应用，用于管理多个获准使用的 Codex 账号。通过浏览器添加账号，再从菜单栏选择，无需终端命令或修改配置文件。确认后，应用会自动完成 Codex Desktop 交接。

Codex Switcher、Codex profile switcher 和 macOS Codex 多账号切换器可以作为本项目的简称或描述，产品正式名称始终是 Codex Account Switcher。

当前 fork 身份：产品网站为 hsjx945.github.io/codex-account-switcher，源码仓库为 github.com/hsjx945/codex-account-switcher；原始上游为 liuzhao1225/codex-account-switcher。

为什么需要 Codex Switcher

OpenAI 提供 ChatGPT 网页版账号切换功能，可以同时保留两个账号，并让聊天、记忆、账单和工作区彼此独立。该官方文档同时明确说明，账号切换功能目前尚不支持 Codex desktop。

Codex Account Switcher 解决的是 macOS 桌面工作流。它不会更改账号权限、合并订阅、合并工作区、增加用量限制或取代 OpenAI 认证，只管理用户本人拥有或获准使用的本地账号配置。

项目如何工作

OpenAI Codex 源码会从当前 CODEX_HOME 目录读取 auth.json。上游认证存储实现也表明，Unix 系统中新建的文件认证会使用仅当前用户可读写的权限。

本项目把每个已保存身份放在相互独立的本地配置目录中。用户确认切换后，应用依次保存当前配置、激活所选认证、核验目标身份，并重新打开 Codex Desktop；如果目标验证或 registry 提交失败，应用会恢复刚保存的原凭证。已经运行的 CLI 进程保留此前状态，新启动的 CLI 使用刚刚选择的认证。
